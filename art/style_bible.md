# Style Bible: Color Clash / Graffiti Idol Visual Language

参考来源：`art/reference/1.png` - `art/reference/23.png`

## 1. 核心视觉定位

这套视觉语言是“高饱和街头涂鸦 + 二次元 Q 版角色 + 手游贴纸 UI”的组合。整体气质年轻、喧闹、轻叛逆、玩具感强，像一本可交互的涂鸦贴纸手账：角色和按钮被厚白边剪出来，叠在高明度城市、票券、喷漆、半调网点和夸张字体之上。

关键词：

- 街头涂鸦
- 赛博流行色
- Q 版战斗偶像
- 贴纸拼贴
- 手机竖屏手游 UI
- 强轮廓、强撞色、低写实
- 轻朋克、轻潮牌、轻幻想

## 2. Art Style

整体为 2D 卡通插画，不追求真实体积或写实材质。角色是日系二次元基础，叠加街头潮流符号、涂鸦喷漆、贴纸边框和手游商业图标。

主要特征：

- 粗黑线稿或深色线稿，外层常有厚白描边，角色像贴纸一样从背景中弹出。
- 色块清晰，阴影简化，局部用高光和反光制造亮面感。
- 角色造型偏夸张，表情直接，姿态动态强。
- 背景和 UI 使用大量图形语言：半调网点、泼墨、喷漆、斜切条、票券、标签、箭头、巨型浅色英文字母底纹。
- 气质介于“潮玩包装”“抽卡手游”“街机游戏菜单”之间。

避免：

- 写实厚涂、电影感渲染、低饱和奇幻、严肃暗黑风。
- 过度精细的真实布料、真实金属、真实皮肤毛孔。
- 极简 UI 或商务 SaaS 式界面。

## 3. Camera Angle

画面多为竖屏手机构图，强调角色或界面元素的正面可读性。

角色/主视觉：

- 常用中近景到全身竖构图。
- 角色面向镜头或 3/4 面向镜头。
- 镜头略低或平视，让角色鞋、武器、手势向前伸出，产生冲击感。
- 多角色海报中使用轻微仰视，让前景角色更有压迫和主角感。

场景/剧情：

- 城市背景多用高机位或平视远景，但被角色前景压住。
- 对话场景倾向 2.5D 舞台式布局：角色大贴片在前，城市或建筑盒子在后。

UI：

- 几乎全部正交展示，强调按钮、卡片和商品网格可读。
- 装饰图形可倾斜，功能信息保持正面。

## 4. Perspective

透视语言是“夸张但不复杂”。它服务于动势和层级，而不是严格真实空间。

规则：

- 角色采用弱透视到中度透视，前伸的手、脚、武器会明显放大。
- 城市建筑使用简化 2 点透视或斜切盒体，边线清楚，细节较少。
- UI 元素大多无透视，像贴纸一样贴在屏幕表面。
- 海报和抽卡页常使用斜向构图、斜切色带和不规则喷漆形状制造速度感。

推荐：

- 角色：局部透视夸张，保持脸部和身体轮廓清晰。
- 背景：透视可以大胆，但细节要后退，避免抢主角。
- UI：不要做真实 3D 透视按钮，保持平面、厚边、贴纸感。

## 5. Proportions

角色比例偏 Q 版，但不是幼儿化。更接近“潮流手办化的少年/少女角色”。

角色比例：

- 头身比约 3.5-5 头身。
- 头部偏大，眼睛大，五官集中。
- 躯干短，四肢较细，但手脚、鞋子、武器可被夸张放大。
- 发型占轮廓比重高，是角色辨识度核心。
- 服装多为短款、分层、街头、朋克或幻想配件混搭。

UI 比例：

- 按钮和卡片尺寸大，适合手机触控。
- 图标比文字更抢眼，文字常被厚描边或色块托底。
- 商城卡片采用 2-3 列网格，商品图占据卡片上半部，价格条在底部。

## 6. Silhouette Language

剪影语言强调“尖、圆、飘、贴”四个方向。

角色剪影：

- 大头、大眼、尖发束、尖角、翼形配件、夸张武器形成第一识别点。
- 发尾、丝带、尾巴、外套、武器常形成向外甩出的弧线。
- 身体核心较小，外轮廓靠发型、鞋、手势和道具扩张。
- 姿态避免完全直立，常有蹲姿、前冲、侧倾、抬手、踢脚。

UI 剪影：

- 贴纸式不规则边缘。
- 圆角矩形、三角形按钮、票券形卡片、喷漆块和黑色标签并用。
- 图标多为厚线简化符号，外加圆形或方形底座。

## 7. Color Palette

色彩是这套风格的第一优先级：高饱和、强对比、荧光点缀，但整体亮度需要受控。参考图的高饱和不是通体发光，而是用局部荧光色压住大面积中明度色块。

主色倾向：

- 电光紫：#6D5BFF / #7A4DFF
- 青绿/薄荷青：#48E0D1 / #9FF4DF
- 荧光黄绿：#CFFF00 / #DFFF00
- 热粉/洋红：#FF36D8 / #FF4AAE
- 活力橙黄：#FFB12B / #FFD84D
- 深墨黑：#222426 / #111318
- 雾灰白：#F2F2F2 / #FFFFFF

使用规则：

- 每个主画面至少有 1 个荧光强调色，通常是黄绿或洋红，但荧光色应集中在按钮、描边、角标、能量边或小面积装饰上。
- 背景可用浅青、淡紫、浅黄做大面积底色，叠半调网点降低空白感。
- 黑白用于增强字标、按钮和贴纸边缘，不作为沉重暗黑底色。
- 灰色常用于未解锁、禁用、遮罩和背景建筑。
- 道具 icon 的主体明度以中高明度为主，避免整颗物体像霓虹灯或宝石灯箱一样过曝。

避免：

- 单一色相铺满全屏。
- 低饱和自然色、写实棕灰、厚重暗蓝。
- 真实渐变金属色作为主视觉。
- 大面积纯白高光、全物体强发光、彩虹渐变堆满主体。

## 8. Materials

材质以“图形材质”而非真实材质为主。道具更接近扁平赛璐璐商品图标，而不是真实 3D、玻璃宝石或高精度渲染模型。

常见材质：

- 贴纸：中等白边、轻投影、轻微错位叠放；白边用于分层，不应厚到吞掉主体比例。
- 塑料/玩具：高明度色块、硬边高光、低粗糙度假想材质，但体积面保持简化。
- 票券/卡片：白底、浅灰半调纹、圆角、彩色描边。
- 喷漆/涂鸦：不规则色块、滴落边、飞溅点。
- 宝石/晶体：仅用于货币钻石等特定资源；普通道具不要默认做成透明玻璃或复杂切面。
- 城市建筑：哑光色块，边缘用青色或紫色描线。

不推荐：

- 真实金属拉丝、皮革纹理、复杂布料编织。
- 高噪声照片质感。
- 重体积雕塑感。
- 高折射透明宝石、复杂多面切割、真实 3D 光追感。

## 9. Lighting

光照是插画化、舞台化、符号化的。

角色：

- 主光柔和，面部保持清晰。
- 阴影为少量硬边色块，不做复杂环境光反弹。
- 边缘常出现青色、紫色、黄绿色轮廓光或色边。
- 高光集中在眼睛、头发、关键道具和亮面鞋上；道具高光应是少量硬边白块或色边，不做大面积镜面反射。

场景：

- 背景多为日间高明度或霓虹化城市，不强调真实太阳方向。
- 建筑可以用雾化远景和低对比灰块退后。
- 重要元素周围用亮色描边或色块托起。

UI：

- 通过白边、投影、描边和色块对比建立层级。
- 禁用状态使用半透明黑/灰遮罩。

## 10. Rendering / Shading Style

渲染是干净的赛璐璐风格，局部带轻微软渐变。

规则：

- 大色块铺色为主，阴影 1-2 层。
- 线稿颜色多为深紫、深灰、黑色，不完全依赖纯黑。
- 头发和眼睛可以更精细，允许多层高光和渐变。
- 服装、皮肤、道具保持简化，避免写实材质拆解。
- 背景使用低细节块面、半调点、轮廓线和轻渐变。
- UI 图标采用矢量感硬边，少量内部高光。
- 道具 icon 应优先表现 2D 赛璐璐色块：1 层主阴影、1 层小高光、少量色边即可。

边缘处理：

- 角色外轮廓优先：深线稿 + 白色贴纸边。
- 道具外轮廓：深色粗线优先，外白边中等厚度；小尺寸下白边约占主体宽度的 3%-6%，不要达到 10% 以上。
- 重要标题：黑/白粗描边 + 高饱和填充。
- 选中态：荧光黄绿外框或底色。
- 未解锁态：灰度 + 锁图标 + 降对比。

## 11. Detail Density

画面整体看似热闹，但信息分层清楚。

高细节区域：

- 角色脸部、发型、武器、主按钮、商品奖励。
- 抽卡页的角色群和主标题。
- 商城卡片中的道具图标和价格。

中细节区域：

- 前景 UI 卡片、菜单按钮、导航标签。
- 对话框头像和姓名牌。

低细节区域：

- 城市背景、远景建筑、灰度地图区域。
- 大面积底纹和半调网点。

密度控制：

- 每屏一个主焦点：角色、商品组、地图节点或弹窗。
- 装饰可以多，但必须低对比或远离关键文字。
- 文本区域需要留白，尤其是对话框和确认按钮附近。

## 12. UI / Icon Style

UI 是贴纸化、街机化、潮牌包装化的混合风格。

按钮：

- 大圆角矩形为主，通常白底或荧光黄绿底。
- 主要按钮：荧光黄绿填充 + 深色粗体文字。
- 次要按钮：白底 + 灰色边框/阴影。
- 禁用按钮：灰度、低对比、锁图标。
- 返回按钮：黑底或深底贴纸，荧光黄绿箭头。

卡片：

- 商品卡片使用暖黄/白底，上方奖励插画，下方价格条。
- 卡片边缘有白描边、轻阴影、圆角。
- 选中态使用荧光黄绿框或底托。

图标：

- 图标用厚线、简化剪影、强色块。
- 常见外框为圆形、圆角方形或三角贴纸。
- 图标内部允许 2-3 色，避免复杂真实图案。
- 小红点、NEW、HOT、感叹号用于提示状态，颜色偏粉红/橙/黄绿。

道具 icon：

- 优先参考商城奖励、票券、资源包里的小图标语言，而不是抽卡主视觉海报。
- 主体应是 2D 扁平赛璐璐道具：正面或轻微 3/4 角度，体积简化，不做真实 3D 渲染。
- 外轮廓为深色粗线 + 中等白边；白边只负责从 UI 底色中分离，不要形成厚厚的贴纸泡沫感。
- 主体颜色控制在 2-3 个主色，加 1 个荧光点缀色；避免彩虹渐变覆盖整个物体。
- 高光使用少量硬边小白块或浅色边，不使用大面积玻璃反光、折射、复杂晶体切面。
- 图标需要更“UI 商品图”而不是“独立海报”：装饰元素少量即可，半调点/喷漆/星星应贴近主体或作为小角标，不要铺满背景。
- 可加入小标签、票券角、锁扣、资源角标等 UI 感元素，但不写复杂文字。
- 在 128x128 尺寸下仍能读出主体类型；不要依赖微小纹理和复杂内部结构。

排版：

- 标题字体粗、圆、挤压感强，常配黑白描边。
- 中文标题可做夸张字重，英文装饰字可低透明度铺在背景。
- 数字和价格必须大而清晰。
- 正文对话使用较普通的粗黑字，保持阅读效率。

装饰系统：

- 半调网点。
- 喷漆滴落。
- 星星闪光。
- 斜向箭头和速度线。
- 票券虚线、条码、标签角标。
- 巨型低透明英文字母作为背景纹理。

### 已定稿菜单 Panel

当前已通过的两个主菜单 panel 资产：

- `assets/generated-ui/panel-start-adventure-v4.png`：开始冒险。
- `assets/generated-ui/panel-continue-journey-v5.png`：继续旅程。

这组 panel 的模板必须保持一致：

- 横向白色贴纸票券卡片，水平摆正，不做大角度倾斜。
- 左侧为大号黑色中文标题，右侧为功能叙事缩略图。
- 中间保留浅灰圆点/孔位装饰，下方保留条码块、圆点、星形等小图形装饰。
- 厚白边、轻投影、圆角、扁平 UI 缩略图画风必须统一。
- 右侧图片只承担叙事差异，不改变 panel 的比例、排版和组件语言。

两张 panel 的功能差异通过“叙事 + 主色”区分：

- 开始冒险：蓝紫/青色为主，内容是传送门、浮岛、晶体桥，表达进入异世界冒险的起点。
- 继续旅程：暖金、橙、青绿、薄荷色为主，内容是地图路线、检查点、城堡/森林标记、目的地门，表达存档进度和继续路线。

生成同系列 panel 时要避免：

- 两张 panel 使用过于相似的蓝紫主色，导致功能不可区分。
- 右侧缩略图变成厚重奇幻概念图、写实插画或高细节地图。
- 改变已定稿模板的标题区比例、孔位位置、装饰块位置或图框大小。
- 加入现代城市、公路、汽车、交通标识、英文 UI 或额外按钮。

## 13. Composition Rules

竖屏布局：

- 主视觉优先适配 720x1280 或类似 9:16 画幅。
- 角色/主物件占画面 45%-70% 高度。
- 底部保留导航、确认按钮或抽卡按钮。
- 顶部保留资源栏、标题或活动横幅。

层级顺序：

1. 主角色或核心商品
2. 主标题/核心行动按钮
3. 资源与奖励信息
4. 导航/系统按钮
5. 背景建筑、纹理、装饰字

视觉动势：

- 多用斜线和曲线，不要全屏网格化静态排版。
- 色带、喷漆、角色肢体和道具可以共同指向主按钮。
- 角色外轮廓和 UI 卡片之间要有足够白边分隔。

## 14. Production Checklist

角色资产：

- 是否有清晰的大头、大眼、强发型剪影？
- 是否有厚白贴纸边或明确外轮廓？
- 是否至少包含一个高饱和识别色？
- 姿态是否有前后层次和动态？
- 细节是否集中在脸、发、道具，而不是全身平均铺满？

场景资产：

- 是否用低细节块面表现城市或地点？
- 是否有青/紫/灰色轮廓线和半调网点？
- 是否能退到角色后面，不抢主焦点？
- 透视是否夸张但可读？

UI 资产：

- 是否像可撕贴纸或票券，而不是标准扁平控件？
- 主按钮是否高对比、触控尺寸足够？
- 禁用、选中、提示、HOT/NEW 是否有统一标记？
- 图标是否厚线、简化、可在小尺寸读清？
- 文本是否保留描边或托底，避免压在复杂图形上？

## 16. Style Boundaries

必须保留：

- 竖屏手游界面感。
- 街头涂鸦与贴纸拼贴。
- 高饱和荧光撞色。
- Q 版二次元角色。
- 厚轮廓、厚白边、半调网点。
- 玩具感、街机感、抽卡商城感。

可以变化：

- 角色主题：天使、恶魔、偶像、运动、神话、都市怪谈等。
- 主色搭配：紫青、橙黄、粉绿都可，但必须有荧光强调。
- 场景地点：城市、屋顶、地图节点、商店、战斗舞台。

不应变化：

- 不要转成写实 3D。
- 不要转成低饱和水彩。
- 不要去掉贴纸边和图形装饰。
- 不要让 UI 过于冷静、现代、商务化。
- 不要让背景细节超过角色和主要按钮。
