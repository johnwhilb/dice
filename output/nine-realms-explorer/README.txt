九界探索地图 · 本地 HTML 交互原型

打开 index.html 即可使用。最终 HTML 已内嵌地图，无需网络、安装或服务，单独复制此文件也可以打开。

操作：
1. 鼠标拖动 / 触屏单指滑动，平移查看完整九界。
2. 滚轮、加减按钮或触屏双指捏合缩放；触控板双指轻扫平移。
3. 点击浮岛选择世界，底部显示探索层数、下一节点与 Boss 状态。
4. 下拉菜单、定位按钮、双击浮岛均可聚焦世界。
5. “查看全图”、左上角返回、键盘 Home 可回到完整地图。
6. 右下角缩略地图支持点击、拖动定位。
7. 方向键平移，＋ / − 缩放（地图获得键盘焦点时）。

本版地图：只保留阿斯加德的云朵；补全世界树树冠；保留九界浮岛、瀑布、冰雪与火山烟气。
当前采用不带神兽的九界与世界树版本，世界之间的间距约增加 1/3；地图逻辑画布扩大至 2400×1600，点击区域和导航位置已同步校准。
初次打开以全图视角展示完整边缘插画，可再放大并拖动探索九界。
顶部与底部为 HTML UI，中央地图为独立图像与九个可点击世界热区。
资源、任务、Boss 与探索状态为示例数据；“进入世界”打开本地预览，并发送 window 的 realm-enter 事件，detail 包含 id/name/floor/next，可供游戏接入。

文件：
index.html — 最终独立 HTML（内嵌地图）。
index.template.html — 便于编辑的源文件，读取同目录 map.png。
map.png — 去云与补全后的地图，使用内置 image_gen 生成。
map.png.prompt.txt — 图片编辑的完整提示词。
map-spacing.prompt.txt — 无神兽版世界间距调整的完整图片编辑提示词。
index-before-guardians.html / map-before-guardians.png — 此次修改前的版本备份。
build.mjs — 使用 Node.js 重新生成内嵌地图的独立 HTML，同时检查脚本语法和地图比例。

九个世界的热区与状态定义在 HTML 的 realms 数组中。
相机和选择接口：window.nineRealmsExplorer。
