# 场景绘制参考

本文整理哥特式恐怖场景的常用元素与空间设计要点，供场景构思、素材选择

| --- | --- |
| 建筑主体 | 哥特式教堂、尖塔、钟楼、庄园、高层建筑、屋顶、拱形窗、雕花立面 |
| 道路与空间结构 | 石板路、狭窄巷道、石桥、拱门、台阶、平台、地下通道、铁栏杆 |

## 二、按场景类型组织素材

### 1. 哥特式城市街道

**核心元素：建筑、道路、街道设施。**

- 建筑：石砌建筑、尖顶屋檐、拱形门洞。
- 空间结构：石桥、台阶、狭窄巷道、铁栏杆。
- 街道设施：街灯、马车、木桶、箱子。
- 破败细节：碎石、破损墙面、悬挂布料。

**设计重点：**高低错落的建筑轮廓、狭窄的视线通道，以及层层叠加的街道空间。

### 2. 墓地与荒野

**核心元素：自然、墓葬、衰败。**

- 墓葬设施：墓碑、墓室入口、石棺。
- 植被：枯树、荆棘、荒草、裸露树根。
- 地形与边界：岩石、泥地、破损围栏。
- 环境氛围：雾气、月光、远处建筑剪影。

**设计重点：**利用自然元素遮挡视线，以不规则地形和重复出现的墓碑制造压迫感。

### 3. 教堂与宗教空间

**核心元素：建筑结构、仪式装饰、光源。**

- 主体结构：高耸拱顶、立柱、彩色玻璃窗。
- 仪式装饰：祭坛、神像、雕塑、烛台。
- 空间设施：吊灯、长椅、铁门、石阶。
- 光影组织：窗户透光、烛火、局部阴影。

**设计重点：**通过高大的空间比例、对称布局和集中的祭坛突出场景中心。


### 4. 医疗、研究与室内空间

**核心元素：功能道具、家具、建筑内部结构。**

- 功能区域：书架、柜子、实验桌、医疗设备。
- 家具与器械：椅子、轮椅、瓶罐、器械支架。
- 空间结构：多层回廊、楼梯、木质地板。
- 叙事细节：破碎物件、杂乱陈设、局部灯光。

**设计重点：**用道具和空间布局暗示这里曾经发生过什么，而不只是填满房间。


## 三、怪物剪影

怪物造型可以从以下特征入手：

- 细长的肢体。
- 异常弯曲的脊背。
- 蓬乱的毛发。
- 不对称的轮廓。

通过剪影表现异常与威胁，不必依赖鲜红血肉。
